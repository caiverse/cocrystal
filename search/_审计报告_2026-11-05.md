# 全库结构图渲染审计（2026-11-05）

管线：坐标候选 A（RDKit depictor + 规范取向）/ E（coordgen）逐分子打分取优 → 端基键双向修正 + 绕母原子转向搜空位 → 非环键键长松弛（环原子钉死 + 防挤压二分） → 清双键 either 标记 → 悬挂环后处理。

本轮（用户选定 E 方案后的"都做"）新增/改动：
1. **不再固定用某一套坐标**：A/E 两份都算，用 `_prpScoreBlk`（键长离群 + 环内角偏差 + 非键合原子挤压）逐分子打分取优；
   再叠加候选 C（非环键键长松弛）二次择优。E 整体优于 A（短键 80→44），但 E 会把非端基 C-C 拉到 2.5 倍，
   故只能逐分子比，不能整体替换。
2. **端基键修正加"转向"**：轴向顶不出去时，把这根键绕母原子偏转（6°→60°，单键端基可全周细扫 3°/格）找空位，
   键长恢复又不制造重叠；双键端基只在 ±30° 内偏（否则羰基会被摆到环另一侧）。
3. **松弛改为"环原子钉死"**：只挪不带环的原子，环保持正六边形（旧版两端对半挪会把六边形压歪，导致松弛结果被打分判负）。
4. **防挤压收尾**：松弛后若原子被挤到半个键长以内，在"原坐标→松弛坐标"之间二分，取刚好不挤的最大比例 —— 键长能修多少修多少，不牺牲原子间距。

### 遗留 8 例（3 短 + 5 长）为什么留着

全部集中在 3 个"极限拥挤"库：`胺取代新型地平（六氟乙酰丙酮）`、`（苯甲酰乙酸乙酯）`、`（二苯甲酰甲烷）`。
分母是 13,447 张抽查图 → 占 0.06%。这些分子同时挂着 3~4 个大体积基团（2,4,6-三氯苯基 / 双 CF₃ 乙酰基 / 苯甲酰），
二维布局本身没有空位，**任何一个方案都必须在"键长"和"原子间距"之间让步**：

| 分子 | 方案 A（depictor，键长最匀） | 方案 E（coordgen） | 现选 | 最终 |
|---|---|---|---|---|
| 三氯苯基·三甲氧基苯基·二氢吡啶 | 键长全 1.000，但两原子挤到 **0.218 键长**（打分 56.4） | 0.665 / 1.289（打分 43.0） | E + 松弛 | **0.694 / 1.259** |
| 2-CF₃苯基·双 CF₃ 乙酰基 | 1.000 / 1.000，但挤压（打分 79.4） | 0.574 / 1.250（43.0） | E + 松弛 | **0.690 / 1.251** |
| 2-NO₂苯基·双 CF₃ 乙酰基 | 1.000 / 1.000，但挤压（44.4） | 0.586 / 1.291（**44.0**） | E + 松弛得 0.940 / 1.293（44.2，差 0.2 分落选） | 0.586 / 1.291 |
| 二苯甲酰甲烷衍生物 | 1.000 / 1.000，但两原子挤到 0.22（84.9） | 0.905 / 1.560（84.4） | E + 松弛 | **0.933 / 1.422** |

即：**放弃 A 不是因为 A 的键长不好，而是 A 把两个原子画到了一起**（图上"叠字"比短键更难读 ——
读者会以为那里缺了原子）。打分把"重叠"罚得比"短键"重是刻意的。
第四行那个 1.422 是"把 1.56 拉回来一部分"后的结果；第三行 0.586 那例，松弛能给到 0.940 / 1.293，
但打分只差 0.2 分没被选中 —— 属打分口径的边界，不是修不了。
这一档分子若要彻底解决，只能上"二维布局超松弛"（把整个分子撑开），已超出渲染层的职责，本轮到此为止。

## 二、线下静态图（首页侧栏 14 张）

原来 `side-structures/struct_01..14.svg` 是 **Python（rdCoordGen + 自写悬挂环规范化）离线生成**的，
与线上 JS 管线**不同源** —— 线上修好不等于线下的也修好，反之亦然。已改为**用线上的同一个 `molToSVG()`**
（`search/_gen_rails.js`，规格 300×240）重生成，`rails.js` 里的文件名不变、无需改引用。

重生成时补了一步**取景归一**：RDKit `get_svg()` 会在画布四周留大片白边（墨迹最高只到 175/240，
即 73%），与旧版 Python 生成器"按最大边归一"的口径不一致，缩小显示时会显得图变小。
`_reframe()` 按真实墨迹 bbox 重算 `transform`：居中 + 撑满主要方向 + 固定 10 px 边距。

实测（14 张，旧 → 新；旧 51.5% 是原 14 张的均值，新 59.9% 是现 14 张）：

| 指标 | 旧（Python 生成） | 新（线上同一渲染器 + 取景归一） |
|---|---|---|
| 墨迹面积占框（14 张均值） | 51.5% | **59.9%** |
| 最小单边留白（14 张里最窄的） | 6.2 pt | **11.9 pt** |
| 左右 / 上下留白对称性 | L=R、T=B（0.0 偏差） | L=R、T=B（≤ 0.09 pt） |

目检（4 列联览 + 逐张 + 首页宽屏实拍）：无歪斜、无交叉双键、无半截键、无贴边裁切。
